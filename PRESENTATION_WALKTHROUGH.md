## 4. Exact Startup Instructions

### Prerequisites
- Node.js v18+ or v20+ installed
- Google Gemini API key configured in `.env`

### Step 1: Start Backend Server
Open Terminal 1 (in the project root):
```bash
cd server
npm install
node server.js
```
- **Local URL**: `http://localhost:3001`
- **Health Check**: `http://localhost:3001/api/health`

### Step 2: Start Frontend Client
Open Terminal 2 (in the project root):
```bash
npm install
npm run dev
```
- **Local URL**: `http://localhost:3000`
- **Network URL**: displayed in terminal for mobile/tablet judge testing on the same Wi-Fi.

### Step 3: Production Build (Optional Verification)
To verify the production bundle:
```bash
npm run build
npm run preview
```

## 5. Environment Variables & Privacy

File location: `.env` (in project root or `server/.env`)

```ini
# Real Gemini API Key (Kept strictly on the backend; never bundled into frontend)
GEMINI_API_KEY=your_google_gemini_api_key_here
PORT=3001
GEMINI_MODEL=gemini-3.8-flash
```

> **Security Guarantee**:
> - `.env` is listed in `.gitignore` and is **never committed to git**.
> - The Vite frontend bundle contains **zero API keys**. All AI inference and vision processing are proxied through the Express backend.

## 6. Judge FAQ & Troubleshooting

| Issue / Question | Rapid Fix during Demo |
|:---|:---|
| **Camera permission prompt appears** | Click **"Allow"** in the browser URL bar lock icon. If camera is blocked by OS privacy settings, switch source to **Screen Capture** or click **"1-Click Test: System Schematic Ingest"**. |
| **Microphone is quiet / no speech output** | Check the Header **Voice Mute Toggle** (`Voice On` / `Muted` or press `M`). Ensure your computer speakers are unmuted. |
| **Port 3000 or 3001 already in use** | Run `netstat -ano \| findstr 3000` or `netstat -ano \| findstr 3001` in PowerShell and terminate the stale process (`Stop-Process -Id <PID> -Force`). |
| **Accidentally clicked Reset** | An explicit confirmation dialog protects against accidental resets. Click **Cancel** (`Esc`) to preserve the live session. |
| **Can GENESIS AI delete files or install malware?** | **No.** Arbitrary shell commands are blocked with `HTTP 403`. Only 6 pre-vetted, read-only inspection operations are allowlisted, and each requires explicit human approval. |
