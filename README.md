# GENESIS AI

**See. Hear. Think. Act.**

GENESIS AI is a multimodal AI assistant built for Hack Day Bengaluru 2026.

### Features
- Image understanding
- Voice interaction using Sarvam AI
- AI reasoning using Gemma 4
- Safe, permission-based computer actions

### Technology
- Gemma 4
- Sarvam AI
- Python
- Web technologies

**Status:** Under development.
